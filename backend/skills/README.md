# HK IPO Analyst — 港股 IPO 智能分析系统

基于 AI 的港股新股申购辅助决策系统。输入一份招股书 PDF，自动完成**文档解析 → 估值对标 → 现金流风险扫描 → 市场情绪打分 → 加权综合评级**的端到端分析。

## 各 Skill 职责

### skill1 — 现金流分析器（Cashflow Analyzer）

**核心问题**：公司的现金流健康吗？有没有致命风险？

对发行人进行 **10 维度**现金流可持续性评估：

| 维度 | 说明 |
|---|---|
| R0 经营造血 | 经营CF是否持续为正 + 趋势方向 + OpCF/营收比率 |
| R1 盈利质量 | CF/NI 背离度 + 营收-CF 增速不匹配（纸面利润检测） |
| R2 自由现金流 | FCF 连续为负 + 趋势 + FCF/营收比率 |
| R3 资本支出合理性 | Capex/OpCF + 投资强度 + 维持性vs扩张性分类 |
| R4 融资依赖度 | 结合行业基准判断筹资依赖是否过高 |
| R5 现金跑道 | 跑道月数 + 敏感性分析（乐观/基准/悲观） |
| R6 现金流结构 | 经营/投资/筹资三流占比结构 |
| R7 营运资金效率 | DSO/DIO/DPO/CCC + 多期趋势 |
| R8 偿债能力 | 利息覆盖 + 短期负债比 + 债务偿还年限 |
| R9 行业对标 | 与行业基准的偏离度（SaaS/医药/金融/地产/消费） |

**数据来源**：现金流量表 + 资产负债表 + 利润表（核心4字段必填，15个扩展字段可选）

---

### skill2 — 文档检索器（Document Retrieval）

**核心问题**：招股书 PDF 里有什么？关键信息在哪儿？

从港股 IPO 招股书 PDF 中提取结构化数据，提供 **7 大能力**：

| 能力 | 说明 |
|---|---|
| 文档概览 | 页数、文本密度、表格数量、章节分布 |
| 章节识别 | 自动识别 18 个标准招股书章节（风险因素、财务资料、募集资金等） |
| 财务模式匹配 | 抽取 13 种财务数据模式（金额、日期、百分比、股票代码） |
| 财务报表定位 | 自动找到合并资产负债表/利润表/现金流量表所在页码 |
| 表格提取+清洗 | 处理合并单元格、去除空行、页码范围过滤 |
| 关键词搜索 | 全文搜索 + 上下文片段 + 高亮 |
| 多关键词联合 | AND/OR/NEAR 三种逻辑跨页联合搜索 |

**依赖**：`pdfplumber`

---

### skill3 — 情绪打分器（Sentiment Scorer）

**核心问题**：这只新股热不热？市场追捧度高吗？

基于 2016-2026 年 **1,184 条**港股 IPO 历史数据的 5 维加权评分模型：

| 维度 | 权重 | 计分方式 |
|---|---|---|
| 认购倍数 | 42% | 7 档阶梯（>1000x→+1.00 到 <1x→-0.50） |
| 中签率 | 21% | 8 档阶梯（稀缺性反向指标） |
| 申购参与度 | 16% | 0.5×申购人数 + 0.5×乙组（机构）占比 |
| 保荐人质量 | 11% | Tier1-Tier4 四级分类 + 基石投资者检测(+0.05) |
| 发行结构 | 10% | 0.6×上市板 + 0.4×募资规模 |

**增强能力**：

| 能力 | 说明 |
|---|---|
| 结论式输出 | `check_sentiment()` — "申购情绪极热，强烈建议申购" 等 5 档结论 |
| 置信度评分 | high/medium/low/none 四级，标注分数可信度 |
| 行业情绪叠加 | 基于同行业近期 IPO 表现做 ±0.08 微调 |
| 历史准确率 | `get_accuracy_stats()` — 模型分数 vs 实际首日收益的 Pearson 相关性验证 |

**数据来源**：`IPO_data.xlsx`（1,184 条记录）

---

### skill4 — 估值检查器（Valuation Checker）

**核心问题**：发行价贵不贵？和同行比怎么样？

将发行人估值倍数与 **14 只**港股已上市同行按 **5 个行业**进行对标：

| 行业 | 同行数量 | 特点 |
|---|---|---|
| SaaS/科技 | 4 只 | 高 P/S 容忍度 |
| 医药/生物科技 | 3 只 | 负利润常见，P/S 为主 |
| 金融/银行 | 3 只 | 低 P/B，高杠杆 |
| 地产/建筑 | 2 只 | 极低 P/B，高负债 |
| 消费/零售 | 2 只 | 稳定倍数，现金流充沛 |

**评分方式**：P/E（权重50%）+ P/S（25%）+ EV/EBITDA（25%）三维加权，缺失权重按比例重分配。输出含同行估值区间（min/median/max）和溢价/折价判定。

**输入**：`market_cap`、`revenue`、`net_income`、`ebitda`（单位：百万港元）

### skill5 — 回测器（Backtest）

**核心问题**：历史上类似 IPO 表现如何？现在是不是打新的好时机？

基于历史数据提供 **首日评分** + **择时分析** + **因子归因**：

| 能力 | 说明 |
|---|---|
| 首日评分 | 7 档价格变动 + 6 档换手率评估 |
| 择时热力图 | 按月份/年份统计平均首日收益，标记牛市/熊市/震荡年份 |
| 因子分析 | 认购倍数分层、保荐人等级、上市板（主板 vs GEM）、行业、发行规模 — 对首日收益的影响 |
| 结论输出 | `check_backtest()` — "历史首日表现极强/偏强/中规中矩/偏弱/很弱" |
| 行业横向对比 | 各行业 IPO 的平均首日涨幅 + 上涨率排名 |

**数据来源**：`IPO_data.xlsx`

---

### skill6 — 编排器（Orchestrator）

**核心问题**：综合来看，这只新股能不能打？

顶层管线，串联 skill1-skill4，**投票式**自动识别行业并分配差异化权重：

| 行业 | 文档 | 估值 | 现金流 | 情绪 | 原因 |
|---|---|---|---|---|---|
| SaaS | 15% | **40%** | 25% | 20% | 估值波动大 |
| 医药 | 10% | 25% | **45%** | 20% | 现金跑道最关键 |
| 金融 | 20% | 30% | 30% | 20% | 均衡 |
| 地产 | 15% | 30% | **40%** | 15% | 负债+现金流优先 |
| 消费 | 15% | 35% | 25% | 25% | 情绪影响大 |

**输出**：

| 输出项 | 说明 |
|---|---|
| 加权总分 | 0-100 分 |
| 风险等级 | 低危风险 / 中高危风险 / 极高危风险（含操作建议） |
| 风险汇总 | 跨现金流/情绪/估值/文档四维的聚合风险清单 |
| 置信度 | high/medium/low，评估数据完整性和各模块可靠性 |
