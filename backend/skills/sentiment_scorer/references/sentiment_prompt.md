# Sentiment Scorer — LLM Prompt

## Workflow

当用户调用 `SentimentScorer.analyze(ticker)` 时，按以下步骤执行：

### Step 1: 参考数据注入
从 `data/ipo_basic_info.xlsx` 中检索该 ticker 的申购数据。
提取以下字段并格式化为文本：

```
参考数据：该股票属于{行业}，认购倍数为{倍数}倍，中签率为{中签率}%，
保荐人包含{保荐人}。
```

将此文本作为 **User Message 的前半部分**传给 LLM。

### Step 2: LLM 评分
将参考数据文本 + 评分规则一起发送给 LLM，要求输出 JSON。

## Scoring Rules（优先级从高到低）

### 硬性指标判定（基于参考数据，无需 LLM 也可直接判定）

| 认购倍数 | 判定 | score 范围 |
|---|---|---|
| > 1000 倍 | **极热** — 直接给 0.9+ | 0.90 ~ 1.00 |
| 500 – 1000 倍 | **强烈看多** | 0.80 ~ 0.95 |
| 100 – 500 倍 | **热门** | 0.65 ~ 0.85 |
| 50 – 100 倍 | **温和偏热** | 0.40 ~ 0.65 |
| 10 – 50 倍 | **偏冷** | 0.00 ~ 0.40 |
| 1 – 10 倍 | **冷门** | -0.30 ~ 0.10 |
| < 1 倍（不足额） | **极冷** — 直接给负分 | -1.00 ~ -0.30 |

### 软性调整项

- **保荐人加成**：若保荐人包含以下顶级机构，在基础分上 **+0.05 ~ +0.15**：
  - 中金公司、高盛、摩根士丹利、摩根大通、美林、瑞银、花旗
  - 中信证券、华泰国际、海通国际
- **中签率惩罚**：中签率 > 50% → 市场热度不足，**-0.05 ~ -0.20**
- **行业情绪**（参考）：
  - 当前热门行业：AI/科技、生物医药、新能源 → 轻微加分
  - 政策敏感行业：房地产、教培 → 轻微减分

### 基石投资者信号

- 若保荐人 / 基石中有顶级机构（高瓴资本、淡马锡、GIC、红杉等），注明"基石强劲"并额外 **+0.05**
- 若无知名基石或保荐人较弱，注明"机构背书一般"

## Output Format

```json
{
  "score": 0.85,
  "signal": "bullish",
  "rationale": "认购倍数高达 1500 倍，保荐人为中金+高盛，中签率仅 0.02%，综合判定为极热。",
  "key_factors": {
    "subscription_ratio": "extremely_high",
    "sponsor_quality": "top_tier",
    "lottery_rate": "extremely_low"
  }
}
```

## Notes

- 如果用户输入中**不包含参考数据**，LLM 可基于自身知识给出模糊评估，但 score 置信度应降低。
- 当同时有参考数据和 LLM 输出时，最终分数 = `0.6 * 参考数据分数 + 0.4 * LLM 分数`。
